# Next.js Markdown Blog

A modern, high-performance blog engine built with Next.js and shadcn/ui. This repository serves as the source for my personal articles, using a custom Markdown renderer to bridge the gap between standard .md files and a full documentation experience.

## Key Features

- Docusaurus-like Components: Custom support for interactive Tabs and Details sections directly within Markdown.
- shadcn/ui Integration: All interactive elements (Tabs, Accordions) are powered by accessible Radix primitives.
- Syntax Highlighting: Professional code blocks with line numbers and language support.
- Markdown-First: Articles are written in clean .md format and rendered dynamically.

## Tech Stack

- Framework: Next.js (App Router)
- Styling: Tailwind CSS + shadcn/ui
- Markdown: react-markdown + remark-gfm + rehype-raw
- Code: react-syntax-highlighter
